# Audit Tool V2 — Deep Audit Evolution

## Context
This is the BubbleStone.ai web audit tool (Python/Flask). It runs inside a Docker container.
Current state: scans only the homepage + crawls max 15 pages. We need a FULL deep audit.

## What to change

### 1. crawler.py — CRITICAL
- Change `MAX_PAGES = 15` to `MAX_PAGES = 500`
- The crawler must follow ALL internal links AND parse ALL sitemap URLs
- Add **maillage interne** (internal linking) analysis:
  - For each page: count incoming internal links, outgoing internal links
  - Detect orphan pages (0 incoming links from other pages)
  - Calculate link depth from homepage
  - Identify pages that receive the most/least internal links
- Add **schema detection per page**: detect which Schema.org types are used (Organization, LocalBusiness, JobPosting, Article, FAQPage, BreadcrumbList, etc.)
- Add **duplicate content detection**: flag pages with identical titles or meta descriptions
- Add **thin content detection**: flag pages with < 300 words
- Add **redirect chain detection**: follow redirects and flag chains > 1 hop
- Add **cache-control header** check per page

### 2. run_audit.py — Add new audit modules
- Add **Schema.org audit**: check for Organization, LocalBusiness, JobPosting, Article, FAQPage, BreadcrumbList across the site (not just homepage)
- Add **internal linking score** based on crawl data
- Add **Core Web Vitals per page** (test top 10 pages by traffic potential via PageSpeed Insights API — free, no key needed: `https://www.googleapis.com/pagespeedonline/v5/runPagespeed?url=URL&strategy=mobile`)
- Update `build_recommendations()` with new schema/maillage/duplicate recommendations
- Update i18n (I18N dict) for ALL new strings in both FR and EN

### 3. tpl_report.html — Add new sections to the report
Add these NEW sections (keep existing ones):

#### a. "Maillage interne" section
- Table: URL | Liens entrants | Liens sortants | Profondeur | Orpheline?
- Visual: bar chart or color-coded depth indicators
- Summary: X orphan pages, average depth, most/least linked pages

#### b. "Données structurées" section (Schema.org)
- Table showing which schema types are present on which pages
- Checklist: Organization ✅/❌, LocalBusiness ✅/❌, JobPosting ✅/❌, Article ✅/❌, FAQPage ✅/❌, BreadcrumbList ✅/❌
- Recommendations per missing schema type

#### c. "Contenu dupliqué" section
- List of pages with duplicate titles
- List of pages with duplicate meta descriptions
- Pages with thin content (< 300 words)

#### d. "Redirections" section
- Table: Source → Destination | Type (301/302) | Chain length
- Flag redirect chains > 1 hop

#### e. "Performance par page" section
- Core Web Vitals for top pages tested
- LCP, FID, CLS per page with color coding

#### f. Enhanced "Crawl / Inventaire" section
- Current page table + add columns: incoming links count, depth, cache-control
- Sortable columns

### 4. tpl_report_en.html — Same changes but in English
Mirror ALL changes from tpl_report.html

### 5. Print / PDF support
Add `@media print` CSS to tpl_report.html and tpl_report_en.html:
- Hide topbar
- Force white background
- Page breaks between sections (`page-break-before: always` on major sections)
- Ensure charts/tables don't break across pages
- Print-friendly colors (no gradients, solid colors)
- Add "Generated by BubbleStone.ai — {date}" footer on each printed page

### 6. DO NOT CHANGE
- app.py (Flask routes) — don't touch unless strictly needed for new data
- Database schema — the results_json field can hold any JSON structure
- Existing report sections that work fine
- The Docker/gunicorn setup

## Technical constraints
- Python 3.11, Flask, no npm/node
- Chrome headless available for PDF generation
- `requests` library for HTTP
- Keep the audit fast: max 10 minutes for a 300-page site
- All text must be bilingual (fr/en) via I18N dict

## Quality requirements
- The report must look PROFESSIONAL — this is a sales tool
- Every section must have clear visual hierarchy
- Tables must be readable even with 100+ rows (pagination or scroll)
- Print output must be clean and usable as a PDF deliverable to clients
