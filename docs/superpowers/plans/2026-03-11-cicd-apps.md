# CI/CD for BubbleStone Apps — Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add automated CI/CD deployment for the 3 BubbleStone apps (555, audit, linkedin) on push to main, and consolidate docker-compose to a single source of truth.

**Architecture:** One GitHub Actions workflow per app. Each workflow SSHes to the server, pulls latest code, rebuilds the Docker image locally, and restarts the service via docker compose. The docker-compose file in the Git repo becomes the single source of truth (symlink from OpenClaw workspace).

**Tech Stack:** GitHub Actions, Docker, docker compose, SSH, bash

**Spec:** `docs/superpowers/specs/2026-03-11-cicd-apps-design.md`

## Chunk 3: Create app deployment workflows

### Task 5: Create deploy-555.yml

**Files:**
- Create: `.github/workflows/deploy-555.yml`

**Context:**
- Triggers on push to main when `apps/555-trend-monitor/**` changes
- SSHes to server, git pulls, docker builds from `ai_trend_monitor/` subfolder, restarts
- Build context is `apps/555-trend-monitor/ai_trend_monitor/` (Dockerfile is inside it)
- Health check on port 5000

- [ ] **Step 1: Create the workflow file**

```yaml
name: Deploy 555

on:
  push:
    branches: [main]
    paths:
      - 'apps/555-trend-monitor/**'
      - '.github/workflows/deploy-555.yml'

jobs:
  deploy:
    runs-on: ubuntu-latest
    environment: production
    steps:
      - name: Install SSH key
        run: |
          mkdir -p ~/.ssh
          echo "${{ secrets.VPS_SSH_KEY }}" | base64 -d > ~/.ssh/deploy_key
          chmod 600 ~/.ssh/deploy_key
          ssh-keyscan -H ${{ secrets.VPS_HOST }} >> ~/.ssh/known_hosts 2>/dev/null

      - name: Deploy 555
        run: |
          ssh -i ~/.ssh/deploy_key ${{ secrets.VPS_USER }}@${{ secrets.VPS_HOST }} bash -s << 'DEPLOY'
            set -e
            cd /opt/repos/bubblestone
            git pull origin main
            docker build -t 555:latest -f apps/555-trend-monitor/ai_trend_monitor/Dockerfile apps/555-trend-monitor/ai_trend_monitor/
            docker compose -f infra/docker-compose.yml -p projects up -d 555
            sleep 5
            curl -sf http://127.0.0.1:5000/ > /dev/null || { echo "Health check failed"; exit 1; }
            echo "555 deployed successfully"
          DEPLOY
```
