# Anthropic en 2026 : les deux moves manquants

Claude Code, Claude Cowork, Computer Use — Anthropic multiplie les agents cette année. Mais deux pièces manquent encore au puzzle.

## La voix native

Aujourd'hui, l'app Claude mobile utilise un pipeline classique :
- **Speech-to-Text (STT)** : ta voix est transcrite en texte
- **Claude** : traite le texte et génère une réponse
- **Text-to-Speech (TTS)** : la réponse est lue par une voix synthétique

Trois étapes, trois latences. Et surtout : Claude ne perçoit jamais les nuances vocales — ton, hésitations, silences. Tout est aplati en texte brut.

GPT-4o Realtime d'OpenAI traite la voix directement, en une seule passe. Latence de 200ms, perception des nuances, interruptions naturelles.

Pour les clients enterprise qui veulent des agents vocaux (support client, ventes, onboarding), cette différence est décisive.

## La console de gouvernance

Déployer 50 agents Claude en production sans interface centralisée ? Cauchemar opérationnel.

Les entreprises veulent :
- Logs centralisés
- Permissions par agent
- Audit trail
- Suivi des coûts
- Limites d'usage

Microsoft a Purview. Anthropic va devoir construire son équivalent pour rester dans la course enterprise.

## Prédiction

Voice API d'ici l'été 2026, console admin avant fin d'année.
